# ADR-0014 — Daily Home and real-time comfort policy

Status: Accepted for Environment 06.

Decision: Home is the default scene UI. The laboratory remains summonable through a small icon or Ctrl+Shift+L. Search uses an invisible native input, Google default per tab, DuckDuckGo as an ephemeral alternative. The actual local clock controls presentation comfort independently of simulated ecological time.

Reason: The scene must serve as an immediately usable new-tab page without compromising simulation correctness or artistic freedom.

Tradeoffs: New-tab extension focus behavior requires actual Firefox testing. Relative color transforms are intentionally provisional, not physically calibrated.

# Known issues — World Foundation 08

1. Firefox browser integration and daily/overnight audio behavior require target-machine testing; automated tests do not certify them.
2. Historical Quiet Hours events are a starting point, not a verified current schedule. Review every imported activity and recurrence.
3. The recovered Quiet Hours operations editor primarily edits weekly blocks. Use the Atelier shared editor for new one-time appointments and event-role labels.
4. Per-date override imports/exports are included, but future synchronization across multiple browsers still requires design. This is browser-local data, not cloud synchronization.
5. Mode entries currently share event timing and category fields; activation/deactivation behavior is not implemented. Do not treat modes as automatic environment switches.
6. Historic 36-hour celestial chapters remain artistic experiments, independent of the authoritative ecological World Clock.
7. Long Voyage original rendering and nested iframe editing still need real-browser longevity, focus and performance review.
